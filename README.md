## 🌐 ECN-Based Proportional Congestion Control for Improved Network Performance

> **Research project focused on improving modern network performance using Explicit Congestion Notification (ECN).**

<br>

<p>

<img src="https://img.shields.io/badge/Computer-Networks-blue?style=flat-square"/>

<img src="https://img.shields.io/badge/NS--3-Simulator-success?style=flat-square"/>

<img src="https://img.shields.io/badge/Research-Project-orange?style=flat-square"/>

<img src="https://img.shields.io/badge/Performance-Analysis-purple?style=flat-square"/>

</p>

### 📌 Overview

This project explores congestion-aware communication by implementing **ECN-based proportional congestion control** using the **NS-3 Network Simulator**.

The objective is to improve throughput, reduce packet loss and minimise latency while maintaining fairness across competing network flows.

### 🔍 Research Areas

- Explicit Congestion Notification (ECN)
- Active Queue Management
- TCP Congestion Control
- Network Simulation using NS-3
- Throughput Analysis
- Latency Analysis
- Packet Loss Evaluation

### 🛠 Technologies

`NS-3` • `C++` • `Computer Networks` • `Linux`

**Project Status**

🟡 Research & Implementation
